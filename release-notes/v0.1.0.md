# 案卷观察台 v0.1.0 完整社区版

这是案卷观察台首个公开完整版。安装包内置截至 2026 年 8 月 14 日整理完成的公开法律资料和双语研究种子，不是首次启动后再下载历史资料的空壳。

## 下载

- Apple 芯片 Mac：`Docket-Observatory-0.1.0-macOS-arm64-unsigned.dmg`
- Intel Mac：`Docket-Observatory-0.1.0-macOS-x64-unsigned.dmg`
- Windows 10/11 x64：`Docket-Observatory-0.1.0-Windows-x64-unsigned.exe`

- 生产依赖清单：`SBOM.cdx.json`

三个安装包均为明确标注的免费社区未签名版本，没有冒充 Apple Developer ID 或 Windows 可信发布者。首次运行可能出现 macOS Gatekeeper 或 Windows SmartScreen 确认，请只从本项目 Release 下载并先核对 SHA-256，不要关闭系统安全功能。

## 完整资料基线

- 1,605 条资料记录
- 1,578 份有效本地 PDF，共 1,345,988,147 字节
- 1,559 个唯一 PDF 内容哈希全部进入全文索引
- 12,259 个研究种子文件，共 500,592,021 字节
- 1,559 份中英文逐文件法律阅读
- 58 份中英文案件整体解读
- SHA-256 完整性链、来源姿态、案件关系、搜索索引和自动化种子

213 份启发式风险命中文件全部保留，没有隐藏、删减、替换或排除。发布审查重新验证了每份文件的 PDF 结构、字节数、SHA-256、受管目录、公开 HTTPS 来源和来源姿态，并保留所有风险标签。详细记录见 `corpus-publication-review.md` 与 `corpus-review-decisions.json`。审查不声称每一页均由人工逐字阅读，也不把正文中出现的密封、保密、隐私或遮蔽措辞自动认定为没有法律效力。

## 无 Key 与可选增强

无 API Key 即可离线使用内置资料、搜索、现有翻译、逐文件解读和案件整体解读；联网后自动发现并整理白名单公共来源的增量更新。用户可在本机设置中自行配置、替换或删除 CourtListener Token、Ollama、OpenAI、Anthropic、Gemini 或 OpenAI 兼容服务的 Key、Base URL 和模型 ID。云端正文处理必须明确授权，质量取决于所选模型。

PACER 仍是正式案卷记录。当前版本尚未实现 PACER 登录、付费下载或自动扣费，不能承诺所有相关案件和文件绝对齐全。AI 输出是研究辅助，不是律师代理或正式法律意见。

# Docket Observatory v0.1.0 Complete Community Edition

This is the first public complete edition of Docket Observatory. It bundles the public legal corpus and bilingual research seed prepared through August 14, 2026; it is not an empty client that downloads the historical baseline after first launch.

## Downloads

- Apple-silicon Mac: `Docket-Observatory-0.1.0-macOS-arm64-unsigned.dmg`
- Intel Mac: `Docket-Observatory-0.1.0-macOS-x64-unsigned.dmg`
- Windows 10/11 x64: `Docket-Observatory-0.1.0-Windows-x64-unsigned.exe`
- Integrity manifest: `SHA256SUMS.txt`
- Production dependency inventory: `SBOM.cdx.json`
- Build provenance: `BUILD-PROVENANCE.json`

All three installers are explicitly labeled zero-cost unsigned community builds. They do not impersonate an Apple Developer ID or a trusted Windows publisher. First launch may require a macOS Gatekeeper or Windows SmartScreen confirmation. Download only from this Release, verify SHA-256 first, and do not disable operating-system security controls.

## Complete Baseline

- 1,605 material records
- 1,578 valid local PDFs totaling 1,345,988,147 bytes
- 1,559 unique PDF content hashes represented in the full-text index
- 12,259 research-seed files totaling 500,592,021 bytes
- 1,559 bilingual document-level legal readings
- 58 bilingual case-level dossiers
- SHA-256 integrity chain, source posture, relationship, search, and automation data

All 213 heuristic review findings remain included; no file was hidden, redacted, replaced, or excluded. The publication review reverified each file's PDF structure, byte size, SHA-256, managed path, public HTTPS source, and source posture while retaining every risk label. See `corpus-publication-review.md` and `corpus-review-decisions.json`. The review does not claim that every page was manually read or that quoted sealing, confidentiality, privacy, or redaction language has no legal effect.

## No-Key And Optional Enhancements

Without an API key, users can immediately use the bundled documents, search, existing translations, document readings, and case dossiers offline. While online, the app discovers and organizes incremental updates from allowlisted public sources. Users control and may replace or delete their own CourtListener token, Ollama, OpenAI, Anthropic, Gemini, or OpenAI-compatible key, Base URL, and model ID. Cloud body processing requires explicit consent, and output quality depends on the selected model.

PACER remains the docket of record. PACER login, paid retrieval, and automatic charges are not implemented in this version, and no source combination proves absolute completeness. AI output is research assistance, not attorney representation or formal legal advice.

## Security And Verification

- No telemetry, advertising SDK, remote user database, or hidden update channel
- Electron context isolation, sandboxing, loopback API boundary, and network allowlist
- RunAsNode, NodeOptions, debugger arguments, and extra file privileges disabled
- ASAR integrity and ASAR-only loading enabled
- macOS DMGs passed `hdiutil verify` and mounted complete-payload inspection
- Windows x64 NSIS passed 7-Zip integrity testing; the application payload is PE32+ x86-64
- GitHub CI, CodeQL, dependency audit, and source security checks passed
